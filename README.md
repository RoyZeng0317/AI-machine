## 基本介紹
這是一款使用 Arduino IDE 進行開發的 AI 對話機器人
目前採用的是 Claude Code 的 AI 模型進行對話
語言有中文與英文可供選擇進行交流

## 韌體體需求

| 韌體名稱 | 版本需求 |
| Arduino ESP32 | 任一版本皆可 |
| 麥克風模組| INMP441 |
| 螢幕 | I2C OLED |
| PowerShell | Winodws 10 、 11等電腦 |
